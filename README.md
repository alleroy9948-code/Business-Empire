# Бизнес-империя

Мобильный 2D бизнес-симулятор. Текущая версия проекта — **v0.7**.

## Что нового в v0.7

- Более выразительная изометрическая карта в ярком мультяшном tycoon-стиле.
- Здания растут вместе с уровнем предприятия и получили дополнительные оконные ряды, фасадные детали и элементы крыш.
- Более мягкая текстура земли, дорожная разметка, деревья, фонари, машины и дополнительные силуэты городской застройки.
- Сохранена мобильная компоновка и существующая игровая экономика.

## Запуск игры

- **В браузере:** откройте [игру на GitHub Pages](https://alleroy9948-code.github.io/Business-Empire/).
- **Локально:** откройте `index.html` в браузере.
- **Публикация:** workflow `.github/workflows/deploy-pages.yml` собирает и публикует сайт при push в ветку `main`.

## Сохранения

Прогресс хранится в `localStorage` браузера на этом устройстве. Он не синхронизируется автоматически между устройствами, а очистка данных сайта может удалить сохранение. Ключ сохранения оставлен совместимым с v0.6.

## Файлы проекта

- `index.html` — игра.
- `.github/workflows/deploy-pages.yml` — публикация на GitHub Pages.
- `.github/workflows/validate.yml` — проверка синтаксиса JavaScript.

## Дальше

Текущая карта остаётся лёгкой SVG-изометрией для мобильного браузера. Для полноценного уровня 3D, близкого к коммерческим играм, следующий большой шаг — объёмные модели зданий, свет и тени, анимации и камера на Three.js или Unity. Android APK — отдельный этап сборки.
