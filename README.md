# Бизнес-империя

Мобильный бизнес-симулятор с интерактивным городом. Текущая версия — **v1.0**.

## Новое в v0.9 — перестроенный 3D-город

- Город перестроен на Three.js: объёмные модели предприятий с отдельными фасадами, окнами, вывесками, крышами и деталями по типам бизнеса.
- Направленный солнечный свет, небесное заполнение, тени и материалы с разной шероховатостью создают объём и глубину.
- Планировка стала просторнее: участки отделены от проезжей части тротуарами; улицы, перекрёстки и переходы выровнены по новой сетке.
- Добавлена набережная с каналом и мостами, остановка автобуса, лавочки, цветники и светофоры с анимацией.
- По улицам ездят автомобили и городской автобус; жители ходят по тротуарам, вода движется, деревья слегка покачиваются, а заводские трубы выпускают пар.
- Карта реагирует на покупки, улучшения и выбор участка. Нажимай на здание, чтобы выбрать его.
- Кнопки **+ / − / ↺** управляют камерой. Перетаскивание карты перемещает обзор, прокрутка меняет масштаб.
- При недоступности WebGL или Three.js включается резервная SVG-карта.

## Запуск

- **[Играть в браузере](https://alleroy9948-code.github.io/Business-Empire/)**
- **[Исходный код](https://github.com/alleroy9948-code/Business-Empire)**

Для 3D-режима браузер загружает библиотеку Three.js с jsDelivr, поэтому при первом запуске требуется интернет. Если загрузить библиотеку невозможно, игра попробует показать облегчённую SVG-карту.

## Сохранения

Экономика, предприятия, найм, производство, договоры поставок и исследования используют прежнюю игровую логику. Ключ локального сохранения оставлен совместимым с v0.6/v0.7. Прогресс хранится в `localStorage` текущего браузера и не переносится между устройствами автоматически.

## Структура

- `index.html` — игра и procedurally-built 3D-город.
- `.github/workflows/deploy-pages.yml` — автоматическая публикация на GitHub Pages.
- `.github/workflows/validate.yml` — проверка синтаксиса JavaScript и ключевых элементов карты.

## Следующий уровень визуала

Сейчас здания построены из геометрии Three.js прямо в коде, а не загружаются из внешних 3D-пакетов. Дальнейший шаг — добавить авторские low-poly модели, детализированные интерьеры, анимацию фасадов, погодные эффекты и более разнообразные районы. Android APK — отдельный этап сборки.
