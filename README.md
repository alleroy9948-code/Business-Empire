# Бизнес-империя

Мобильный 2D бизнес-симулятор. Стартовая версия проекта для GitHub — **v0.6**.

## Запуск игры

- **Локально:** откройте `index.html` в браузере.
- **На GitHub Pages:** в настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации. Workflow `.github/workflows/deploy-pages.yml` опубликует игру при push в ветку `main`.

## Сохранения

Прогресс игры хранится в `localStorage` браузера на этом устройстве. Данные не синхронизируются автоматически между разными браузерами или устройствами. Очистка данных сайта может удалить сохранение.

## Структура

- `index.html` — игра, версия 0.6.
- `.github/workflows/deploy-pages.yml` — публикация на GitHub Pages.
- `.nojekyll` — отключает обработку Jekyll.
